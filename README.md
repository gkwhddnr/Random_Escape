# Random Escape

> 매번 형태와 배치가 달라지는 방에서 살아남아 출구를 찾아가는 2D 턴제 미로·퍼즐 게임

🎮 **[게임 플레이하기](https://gkwhddnr.github.io/Random_Escape/)**

## 게임 개요

**Random Escape**는 공격할 수 없는 플레이어가 적과 함정, 변화하는 벽을 피해 제한된 턴 안에 탈출하는 게임입니다.

플레이어가 한 칸 움직일 때마다 적과 환경도 행동합니다. 출구에 도착하면 현재 월드가 사라지고 같은 씬 안에서 새로운 랜덤 월드가 생성됩니다. 스테이지가 높아질수록 방의 크기와 형태, 배치 요소 및 확률 패턴이 달라집니다.

- 장르: 2D 턴제 미로·퍼즐
- 엔진: Unity 6.5 (`6000.5.5f1`)
- 프로젝트 기반: Unity 2D Core
- 최종 플랫폼: WebGL
- 배포: GitHub Pages

## 핵심 특징

### 랜덤 월드

- 실행할 때마다 새로운 랜덤 시드로 월드 생성
- 사각형뿐 아니라 오각형, 육각형 등 다양한 다각형 방 지원
- 스테이지 진행에 따라 필드 크기와 배치 구성이 변화
- 플레이어와 출구 사이의 최소 거리 보장
- 시작 지점 주변에 최소 한 칸 이상의 안전한 이동 공간 보장
- 시작 직후 함정·출구·적에게 강제로 노출되는 불합리한 시드 방지
- 경로 탐색을 통해 출구 도달 가능 여부 검증

### 턴 기반 진행

한 번의 플레이어 이동은 다음 순서로 처리됩니다.

1. 플레이어 이동
2. 아이템·함정·출구·적 접촉 판정
3. 내부 고정 벽과 특수 벽 변화
4. 출구 이동 여부 판정
5. 적 행동
6. 승리·패배 조건 판정

벽에 막힌 이동은 턴을 소비하지 않습니다. 남은 턴은 맵 크기와 배치 요소를 기준으로 계산되며 최대 50턴으로 제한됩니다.

### 플레이어와 적

- 플레이어는 공격 기능이 없습니다.
- 적과 접촉하면 플레이어가 피해를 받고 해당 적은 사라집니다.
- 큰 적 피해량: 2
- 작은 적 피해량: 1
- 체력이 0이 되면 게임 오버
- 흰 하트는 남은 체력, 검은 하트는 소멸한 체력을 표시

적은 플레이어가 턴을 사용한 뒤 확률에 따라 행동합니다.

- 큰 적: 추적 / 무작위 이동 / 정지, 행동 시 1칸 이동
- 작은 적: 정지 / 1칸 이동 / 2칸 이동
- 행동 확률은 월드 시드와 스테이지에 따라 상한·하한 범위 안에서 변화
- 작은 필드에서는 적이 등장하지 않을 가능성이 높음

### 함정

함정을 밟으면 다음 효과 중 하나가 확률로 적용됩니다.

- 즉사
- 체력 1 감소
- 효과 없음
- 다음 행동 한 번 쉬기

기본 확률은 `즉사 20% / 체력 -1 30% / 무시 30% / 턴 쉬기 20%`입니다. 실제 확률은 스테이지별 기믹에 따라 제한된 범위 안에서 변화합니다.

### 벽 시스템

- 바깥 경계 벽
  - 방의 형태를 구성하며 플레이 중 이동하거나 사라지지 않음
- 내부 고정 벽
  - 맵 크기와 시드에 따라 최대 4개까지 배치
  - 일정 확률로 빈 위치에 추가 생성
- 특수 벽
  - 여러 개 생성 가능
  - 플레이어 이동 후 확률에 따라 생성·이동·리스폰·소멸
  - 변화 후에도 출구로 향하는 유효 경로 보장
- 일부 스테이지는 벽이 많이 등장하고 변화 확률이 높은 벽 격변 라운드로 구성

### 아이템과 탈출 조건

아이템 수는 필드 크기에 비례하여 `0 ~ n개` 범위에서 결정됩니다.

- 노란 아이템
  - 체력이 부족하면 체력 1 회복
  - 체력이 가득 차 있으면 남은 턴 증가
- 파란 열쇠
  - 잠긴 출구를 여는 조건 아이템

스테이지 조건은 다음 중 하나가 선택됩니다.

- 조건 없이 출구 도착
- 파란 열쇠를 획득한 뒤 탈출
- 노란 아이템을 지정된 수량 이상 획득한 뒤 탈출

조건을 만족하기 전까지 출구는 닫힌 이미지로 표시되고 이동하지 않습니다. 열린 출구는 일반 스테이지에서 낮은 확률로 이동하며, 특정 스테이지에서는 이동 확률이 크게 증가합니다.

## 조작 방법

| 입력 | 기능 |
|---|---|
| `W`, `A`, `S`, `D` | 상하좌우 이동 |
| 방향키 | 상하좌우 이동 |
| `Enter` / `Space` | 게임 시작 |
| `R` | 게임 오버 후 다시 시작 |
| `다시 시작` 버튼 | 새 캠페인 시작 |

## 게임 오버와 기록

게임 오버 화면에서는 다음 정보를 보여줍니다.

- 사망 또는 실패 원인
  - 큰 적 또는 작은 적의 공격
  - 함정 즉사
  - 함정 피해로 체력 소멸
  - 남은 턴 소진
- `Current Level`: 게임 오버된 스테이지
- `Best Level`: 지금까지 도달한 최고 스테이지
- `다시 시작` 버튼

`Best Level`은 `PlayerPrefs`에 저장되어 게임을 다시 실행해도 유지됩니다. Current Level은 하늘색, Best Level은 금색으로 구분됩니다.

### 로컬 WebGL 빌드 실행

WebGL 빌드는 브라우저 보안 정책 때문에 `index.html`을 직접 열기보다 로컬 HTTP 서버를 사용해야 합니다.

```bash
cd WEB
python -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000`으로 접속합니다.
